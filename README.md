# MediCore Central

MediCore Central is a healthcare application designed to streamline patient data management and symptom tracking. It provides a structured platform for recording, monitoring, and reviewing patient information with a focus on usability and reliability.

---

## 📌 Key Features
- Patient symptom logging and centralized records  
- Intuitive dashboard for healthcare professionals  
- Secure data handling and structured workflows  
- Simple deployment and maintenance process

## 🛠️ Technology Stack
- **Frontend:** React, TailwindCSS  
- **Backend:** Node.js, Express  
- **Deployment:** AI Studio
